# RHCSA 10 Practice Project

This project is a hands-on practice environment for preparing for the Red Hat Certified System Administrator (RHCSA) 10 certification. It focuses on real-world system administration tasks commonly tested in the RHCSA exam, with an emphasis on Linux command-line skills, configuration, troubleshooting, and system maintenance.

The goal of this repository is to help build confidence in core RHEL 10 administration concepts by working through practical exercises in a lab environment. Each task is designed to reinforce essential skills such as user and group management, file permissions, storage configuration, software installation, service control, networking, SELinux basics, and system troubleshooting.

## Objectives

- Practice RHCSA 10 exam-style tasks in a Linux environment
- Strengthen command-line administration skills
- Learn and validate core Red Hat Enterprise Linux 10 concepts
- Improve troubleshooting and system management confidence

## Focus Areas

- User and group administration
- File ownership and permissions
- Filesystem and storage management
- Package management with RPM and DNF
- Service management with systemd
- Networking and firewall configuration
- SELinux context and policy basics
- Shell scripting and automation

## Notes

Use a dedicated virtual machine or lab environment for these exercises. Work through each task carefully, verify the results, and treat the project as a practical learning path toward RHCSA readiness.
